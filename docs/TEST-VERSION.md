# ProjectEye Enhanced 1.0.0-beta.2

第二个本地测试版，基于 Planshit/ProjectEye 1.4.3。保留原有护眼提醒，增加休息时的系统媒体暂停与可选恢复。

## 开始使用

- 安装版：运行 Setup.exe，默认安装到当前用户的独立目录，不需要管理员权限；开始菜单中启动 ProjectEye Enhanced beta.2。
- 便携版：把 ZIP 完整解压到可写的新目录，再运行 ProjectEye.exe。请不要覆盖原版目录或在 ZIP 内直接启动。
- 请从托盘正常退出其他 ProjectEye 实例，避免两套提醒同时出现。增强版使用独立单实例锁和启动快捷方式；保留原版目录及配置。
- 默认20分钟提醒、20秒休息。托盘右键进入设置，按需修改并点击“应用”。
- “媒体控制”中手动开启自动暂停；自动恢复默认关闭，需先开启暂停。所有会话模式会暂停当前所有支持系统媒体控制的正在播放内容，请先用测试媒体验证。
- 网易云需开启 SMTC；Feishin 在 Settings → Hotkeys 中开启 Enable Media Session。播放器必须先向 Windows 注册媒体会话。

## 结束休息后显示桌面

在“设置 → 行为”开启“结束休息时最小化其他窗口”（默认关闭），点击应用。开始休息不改变窗口，倒计时期间仍显示遮罩；已开始的休息结束、跳过、取消或离开时，遮罩关闭前最小化一次当前虚拟桌面、所有屏幕上的普通窗口。直接跳过初始提醒不触发。

窗口不会自动恢复；从任务栏手动打开即可。中途修改开关只影响下一轮。媒体暂停/恢复完全沿用媒体设置，音频可能在后台恢复。处理最多等待200毫秒，无边框置顶悬浮/贴边窗口保留原状，避免破坏伸缩；部分窗口失败仍按时关闭并托盘提示。这不是桌面锁定，后续新弹窗或主动弹出的播放器仍可能显示。

## 已测行为与限制

Windows 10 22H2 上已验证原提醒、设置持久化、20次隔离计时周期、双屏遮罩和人工睡眠/唤醒。PotPlayer 261021（1.7.23172）与网易云3.0.15启用SMTC后的实际暂停/恢复通过。

Edge和Feishin可能发送重复暂停通知，此时按保守规则仅暂停、不恢复；这是预期保护。切换内容、播放器重启、会话身份改变、取消休息或退出程序时也不会擅自恢复。媒体控制失败不阻断护眼提醒。

Windows 11、不同DPI组合及长期稳定性仍需实际测试。本测试版未数字签名，已有 Newtonsoft.Json 12.0.2 的高危依赖告警尚未处理；仅用于当前本机测试，不代表正式发布已通过。没有新增应用运行时依赖；需要 Windows 10 1809+ 与 .NET Framework 4.5或兼容的更新版本。

## 数据、更新和移除

配置在程序目录 Data/config.xml，统计库在 Data，诊断在 Log。媒体日志不保存标题、艺术家或播放路径，也不上传数据。反馈问题时提供版本、播放器版本、操作步骤和必要日志，发送前检查其他日志是否包含个人信息。

本测试版停用上游自动更新，后续测试包需手动安装到新目录。退出旧增强版后，可备份并复制其 Data 到新版本目录；不要在程序运行时复制数据库。跨版本配置迁移尚未验收。

安装版可在 Windows“应用和功能”中卸载，或使用 Windows PowerShell 运行同目录 Remove-TestVersion.ps1。请先托盘退出程序；卸载会将整个安装目录连同 Data/Log 移入系统回收站，不永久删除，必要时可还原。便携版退出后把整个目录移入回收站即可。请自行关闭设置中的开机启动后再移除。

## 建议反馈

记录提醒是否按时、遮罩覆盖、音效、跳过、统计、设置重启保留，以及媒体暂停/恢复有无误操作。遇到异常请保留包旁的 SHA256SUMS.txt 和程序日志。24小时实际使用由用户测试，不在 Codex 中等待完成。
