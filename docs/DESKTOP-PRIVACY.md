# 休息结束显示桌面（beta.2）

按用户确认的方案新增“设置 → 行为 → 结束休息时最小化其他窗口”，默认关闭。旧XML缺少MinimizeWindowsAfterRest时仍为false；设置在RestService.Start时快照，中途修改仅影响下一轮。

只有真正开始倒计时后，正常完成、跳过、取消及离开检测隐藏遮罩前执行一次。提醒阶段直接跳过只关闭提示，不枚举窗口。正常退出调用Shutdown，不遍历桌面。媒体设置与恢复资格不变，允许后台恢复播放；窗口永不自动还原。

## 实现边界

DesktopControlService使用独立DesktopWindowMinimizer；RestService的异步结束任务串行去重，多屏或多次取消共享同一任务。MainService.BeforeLeave先等待结束，TipViewModel跳过命令也等待同一任务，不提前隐藏遮罩。

Win32 EnumWindows、IsWindowVisible、IsIconic、DWM cloaking与官方IVirtualDesktopManager选择当前虚拟桌面的可见普通窗口；所有显示器均覆盖。排除桌面、主副任务栏、工具窗口、隐藏/已最小化窗口及当前所有TipWindow原生句柄；不读取窗口标题，不模拟Win+D，不保存自动还原状态。窗口句柄选择有内存内的测试过滤能力，原生测试仅操作自身夹具，不操作用户应用。

ShowWindowAsync发出最小化，短时轮询状态；总等待预算200ms，内部190ms截止并取消剩余命令。未结束的原生调用不重叠重试，后台迟到结果不再发后续最小化命令。系统调度可能使实际返回略晚于200ms；不宣称硬实时。原生请求发出后，其在目标窗口线程中的最终处理时机不受本应用控制。

失败、超时或身份无法确认仍关闭遮罩并托盘提示，不阻塞弹窗。Desktop日志仅UTC、数量和结果码，上限每日1MiB；不记录句柄、进程名、窗口标题、媒体内容。此功能不是桌面锁定，之后新弹窗、播放器主动显示或用户打开窗口仍可能露出内容。管理员或特殊应用窗口可能拒绝最小化；不提权、不强制最小化。

## 用户反馈修复

用户确认普通窗口最小化、双屏遮罩及PotPlayer恢复均正常，但OpenCodex Monitor贴边伸缩受影响。其当前源码在停靠时置顶并隐藏任务栏入口；新增通用规则排除无边框置顶悬浮窗，保留自身停靠行为，不使用进程/标题白名单，不改Monitor源码。增加相同窗口样式的原生夹具。

用户指出205057-408的崩溃日志：App.OnStartup及测试服务访问出现NullReferenceException。该轮确有其他实例占用mutex；提示框的嵌套消息循环让测试ApplicationIdle在服务初始化前执行，测试Shutdown又使启动过程继续访问Application.Current。修复为在OnServiceInitialized后调度测试，并使用本实例Shutdown且立即return；脚本另有进程预检。该原始失败日志保留，不把它说成没有产品异常日志。
