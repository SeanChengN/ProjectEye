# beta.4 维护和设置界面

版本统一来自packaging/test-release.json，目标net45、业务依赖版本与媒体策略均保持不变。此版本不包含系统修复。正式Release、HiBit深度清理、Windows11和长期稳定性仍不属于本轮通过项。

## 使用与数据规则

先托盘正常退出，再运行Setup。默认沿用经注册、产品标记及可信清单核验的旧安装路径；beta.1/2/3可覆盖升级，Data、Log和未知文件不覆盖，升级前备份并校验，失败回滚。卸载留下的普通空子目录允许原地重新安装，含文件的任意目录仍会拒绝。

Windows应用和功能的卸载入口指向本产品Inno EXE `uninstall/unins000.exe`；安装版的ProjectEye.Maintenance.exe无参数启动也会转交它。没有PowerShell、cmd、wscript等通用宿主。确认文案明确说明配置、统计、日志及目录内其他文件都会回收。便携版没有安装注册，退出后手动将专用目录移入回收站。

卸载默认回收**整个专用安装目录**。维护模块校验产品、可信清单、文件完整性、重解析点、路径边界、运行状态及用户文件占用，再移除仅属于本路径的注册和快捷方式。Inno开放的卸载数据文件留待自身收尾，其余文件先移入同卷独立暂存目录后送系统回收站；Inno释放记录后回收剩余安装目录及已退出的工作副本。取消卸载走Inno取消流程，不启动移除操作；工作副本退出后回收，不留ticket。

同安装恢复历史只按完整规范化安装路径、产品/清单/文件哈希验证后回收。支持历史upgrade事务、beta.3数据恢复清单及可信旧卸载助手。归属不明、哈希改变、格式不支持的记录保留；绝不清空共享恢复根目录或其他安装的备份。恢复根为空时回收根目录。系统回收站中的内容由用户自行决定最终清空，软件不永久删除。

失败不得显示成功；文件占用在更改注册前停止。升级回滚沿用事务入口：使用同候选便携包维护EXE `--rollback --transaction "完整恢复目录"`；需退出程序，篡改过的候选或备份会被拒绝。卸载完成会回收这些历史备份，因此不再提供应用自己的数据恢复副本；仍可从系统回收站找回。

## 中文界面和结果接口

安装/卸载只使用简体中文，语言文件固定为Inno6.2.2匹配版本，保留作者与来源（packaging/THIRD-PARTY-NOTICES.md）。安装脚本和语言文件因Inno工具链需要使用UTF-8 BOM，中文字体为Microsoft YaHei UI。

维护命令返回退出码，`--result <路径>`写UTF-8 JSON（success/code/message/recovery/utc）和相邻`.txt`中文消息；Inno通过MultiByteToWideChar(CP_UTF8,MB_ERR_INVALID_CHARS)显式解码独立文本，不展示JSON。稳定错误码包括E_RUNNING、E_LOCKED、E_ACCESS、E_PATH、E_REPARSE、E_INTEGRITY、E_MISSING、E_CONFLICT、E_VALIDATION；测试注入为E_TEST_FAILURE。卸载中的回收异常也返回失败，不伪造成功。

## 设置滚动条

只有OptionsWindow使用专用模板，六个可滚动设置页都预留右侧12个逻辑像素。轨道固定可见、滑块不随悬停淡出或收窄，内容与轨道隔开；无溢出时保留禁用轨道。Blue/Dark均使用动态主题颜色，滚轮、拖动与键盘沿用WPF标准ScrollViewer/ScrollBar行为，不改变其他窗口。

## 验收边界

维护测试编译相同代码并隔离HKCU/快捷方式常量；完整Inno流程测试额外隔离AppId，不替换用户实际注册。真实测试覆盖空子目录、新装、三轮同路径卸载重装、beta.2/3覆盖、重复安装、占用错误、数据哈希和系统PowerShell/实际安装前后快照。WPF测试覆盖全部设置滚动页、两主题、100/150/200%渲染及延迟后的宽度和底部可达；保留渲染图供检查。

实际中文用户名登录、操作系统DPI切换、现场拖动和安装/卸载窗口目视验收须与程序内布局/渲染断言区分，未完成则明确列为待验。最终候选与结果见[BETA4-VALIDATION.md](BETA4-VALIDATION.md)。
